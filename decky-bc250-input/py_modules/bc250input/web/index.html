Quick phrases

Channel chips add a prefix; tap the selected one again to clear it. Phrases send at once with the selected channel. "Enter" off types the text without submitting it. "Live" types every key on the console as you press it (Return and the Enter button press Enter); chips are not added in Live mode. Edit adds or removes chips and phrases.
